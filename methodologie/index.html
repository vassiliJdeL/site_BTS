Comment lire le site

Cette page n'ajoute aucune couche de méthode supplémentaire. Elle sert seulement à expliquer comment lire le catalogue public, une fiche BTS, puis le document de travail associé.

Lire la page Référentiels

25 BTS publiés désigne le périmètre actuellement visible sur le site public.

17 en CCF et 8 en ponctuel ne forment pas une troisième catégorie : ces deux chiffres répartissent simplement les 25 BTS publiés selon la modalité d'évaluation du support concerné.

Dans le tableau, chaque ligne indique le support évalué, la modalité, la base documentaire, puis l'accès à la fiche web et au DOCX.

Lire une fiche BTS

Chaque fiche suit la même logique. Elle commence par dire quel document est évalué, puis dans quel cadre.

Elle précise ensuite ce que le jury regarde et sur quelle base documentaire cette lecture repose.

La formule base documentaire n'est pas une catégorie d'épreuve. Elle désigne seulement le niveau d'appui disponible : grille publique, critères officiels explicites, ou reconstitution fondée sur des sources convergentes.

Utiliser le DOCX

Le DOCX associé n'est pas un simple export. C'est un support de travail destiné à l'évaluation, à l'harmonisation ou à la préparation d'un jury.

Il reprend la structure de lecture proposée sur la fiche web, dans un format exploitable par une équipe.

Aller plus loin

Pour revenir au catalogue, consultez les référentiels BTS. Si vous voulez voir comment cette base s'articule avec Xénophon dans un usage réel, la page Démo est le bon point d'entrée.
